# ⚙️ `actions` — Pipeline Steps for Files

The `actions` package turns every function of the library that takes **one main value and
returns one result** into an `Action` from
[`simplibs-actions`](https://pypi.org/project/simplibs-actions/). An action is the function
with its options bound in advance: constructed once, then called with the one value that
changes — which is what makes steps chainable into a pipeline.

```python
from simplibs.actions import ForEach
from simplibs.file.actions import ReadText, WriteAggregated
from simplibs.path.actions import CollectFiles
from simplibs.path.rules import HasSuffix

merge_notes = (
    CollectFiles(include_filter=HasSuffix(".md"))      # root folder -> list of paths
    >> ForEach(ReadText())                             # paths       -> list of texts
    >> WriteAggregated(path="build/all_notes.md")      # texts       -> the written Path
)

merge_notes("notes")                  # -> Path('<cwd>/build/all_notes.md')
await merge_notes.acall("notes")      # the same, off the event loop
```

Actions are **not** exported from `simplibs.file` itself — they are a domain of their own,
imported through `simplibs.file.actions`, which defines `__all__`. Twenty-six actions in
five groups: **read**, **write**, **destinations**, **operations** and **inspect**.

## How an action is built and called

Each action is generated by `create_action` from its function. One parameter is named as
the *main input* (`main_param`); **every other parameter** becomes a keyword-only
*constructor option*.

```python
action = WriteText(path="out/report.txt", newline="\r\n")    # options
action("first line\nsecond line\n")                          # main input
# -> <cwd>/out/report.txt   (the file now holds CRLF line endings)
```

* **Constructor options are validated** by the same annotations as the function's
  parameters — a wrong type or value is a `ValidationError` at construction
  (`ReadText(encoding="rot13")`, `FileHash(chunk_size=0)`). A *missing required* option is
  a plain `TypeError` (`WriteText()`, `CopyFile()`).
* **The main input is validated** when the action is called.
* **Errors raised by the function surface unchanged** — an action adds no layer of its own
  (`NotFoundError`, `StateError`, `AccessError`, `AlreadyExistsError`, `ConversionError`, ...).
* **The class docstring is the function's docstring**, and `_input_type` / `_output_type`
  expose the annotations for tooling.

## Content or path — which one flows?

A writer needs two things: *what* to write and *where*. A pipeline step has room for only
one of them as its input, so the library offers **both**, as sibling actions over the same
function:

| The **content** flows — the path is an option       | The **path** flows — the content is an option       |
|-----------------------------------------------------|------------------------------------------------------|
| `WriteText(path=...)`                               | `WriteTextTo(text=...)`                              |
| `WriteBytes(path=...)`                              | `WriteBytesTo(data=...)`                             |
| `WriteLines(path=...)`                              | `WriteLinesTo(lines=...)`                            |
| `WriteAggregated(path=...)`                         | `WriteAggregatedTo(parts=...)`                       |
| `WriteJson(path=...)`                               | `WriteJsonTo(data=...)`                              |
| `AppendText(path=...)`                              | `AppendTextTo(text=...)`                             |
| `AppendBytes(path=...)`                             | `AppendBytesTo(data=...)`                            |
| `CopyFile(destination=...)` — the **source** flows  | `CopyFileFrom(source=...)` — the **destination** flows |

Rule of thumb: a **single** target fed by a changing content is `Write*`
(`... >> WriteText(path=target)`); the **same** content written to many targets is `*To`
(`ForEach(WriteTextTo(text="# TODO\n"))`).

## Shared options

The writers and readers share a small vocabulary of options. Each card lists which of them
it has; what they mean is described once, here.

| Option      | Type              | Meaning                                                                                       |
|-------------|-------------------|-----------------------------------------------------------------------------------------------|
| `encoding`  | `EncodingName`    | A text encoding Python can both encode and decode with. `"rot13"`, `"base64"` and unknown names are rejected up front. Readers default to `"utf-8-sig"` (a BOM is tolerated), writers to `"utf-8"` (no BOM). |
| `errors`    | `EncodingErrors`  | `"strict"` (default), `"ignore"`, `"replace"`, `"backslashreplace"`, `"surrogateescape"`, `"surrogatepass"`. |
| `newline`   | `NewlineMode`     | The line ending written for every `"\n"`: `"\n"` (default), `"\r\n"`, `"\r"`, or `None` for the platform's own. |
| `overwrite` | `bool`            | `False`: an existing target raises `AlreadyExistsError` instead of being replaced. Default `True` for writers, `False` for copy and move. |
| `use_draft` | `bool`            | `True`: the data goes into a draft that replaces the target atomically, so a failure never damages the old file. `False`: written in place (faster, but a failure can leave a partial file). Default `True` for writers, `False` for appenders. |
| `sync`      | `bool`            | Force the data to stable storage (survives a power loss; slower). Default `False`.             |

Every writer **encodes in memory first**, so an unencodable character (`ConversionError`)
fails before the disk is touched and an existing file stays intact. The target's folder is
created when missing; a directory at the target is a `StateError`.

## What changes the disk

| Group          | Changes the disk?                                                      |
|----------------|------------------------------------------------------------------------|
| `read/`        | No — read only.                                                        |
| `inspect/`     | No — one `stat` or a read of the content.                              |
| `write/`       | **Yes** — writes or appends the target file.                           |
| `destinations/`| **Yes** — same as `write/`.                                            |
| `operations/`  | **Yes** — copies, moves, deletes or creates a backup.                  |

Every action that changes the disk returns the **normalized `Path`** of what it produced —
the target, the destination, the backup, the deleted entry — so the next step can carry on
with it.

## Composition

```python
step_a >> step_b          # run step_b on the result of step_a      (a flat sequence)
step_a & step_b           # run both on the same input              -> (result_a, result_b)
step_a | fallback_step    # run fallback_step if step_a raises
```

A `Rule` is a valid step on either side: `IsTextFile() >> ReadText()` verifies the input,
passes it on **unchanged** (a `guard`), or raises the rule's own failure card. See the
[file rules](README_FILE_RULES.md) and the
[path rules](https://pypi.org/project/simplibs-path/) — that is why predicates have no
action of their own.

## Async

All twenty-six actions are synchronous, so `await action.acall(data)` runs them in a worker
thread (`asyncio.to_thread`) — the right model for blocking file-system calls — and a whole
pipeline can be awaited the same way.

## What is not here

* **`iter_lines`** — a generator is consumed once and cannot be logged or re-run by the
  action machinery; pipelines use `ReadLines`.
* **`is_text_file`** — a `bool` is not a pipeline value; use the
  [`IsTextFile`](README_FILE_RULES.md#istextfile) rule as a gate.
* **`SafeFileWriter`** — a context manager, not a function from one value to one result.
  Every writer here already goes through it.

# Read

All four read a **regular file** (a symlink is followed) and raise `NotFoundError` if it
does not exist, `StateError` if it is not a regular file, and `AccessError` if the OS
refuses the read. The input is a path (`PathLike`).

### `ReadText`

Wraps [`read_text`](logic/README_FILE_READ.md#read_text) — the whole file as one string.

**Constructor options:**

* `encoding` (*EncodingName*, default `"utf-8-sig"`): A BOM is removed if present; files
  without one are fine.
* `errors` (*EncodingErrors*, default `"strict"`): How to treat bytes that do not decode.

**Main input:** a path (`PathLike`). **Returns:** `str`.

**Example usage:**

```python
ReadText()("notes.txt")                             # -> 'line one\nline two\n'
ReadText(encoding="cp1250")("old_export.txt")       # a legacy Czech export
ReadText(errors="replace")("damaged.txt")           # undecodable bytes become '\ufffd'

texts = CollectFiles(include_filter=HasSuffix(".md")) >> ForEach(ReadText())
```

**Notes.** Line endings are normalized to `"\n"` (`"\r\n"` first, then a lone `"\r"`) — the
same result as `Path.read_text`. A caller who needs the exact bytes of the line endings
uses `ReadLines(keep_ends=True)` or `ReadBytes`. Bytes that are not valid text in the
encoding are a `ConversionError`.

<details>
<summary>🔍 Under the hood</summary>

```python
ReadText = create_action(read_text, main_param="path", class_name="ReadText")

# the function it wraps, in short:
def read_text(path, *, encoding="utf-8-sig", errors="strict") -> str:
    source = normalize_path(path)
    text = decode_bytes(read_bytes(source), source, encoding=encoding, errors=errors)
    return text.replace("\r\n", "\n").replace("\r", "\n")      # "\r\n" first, or it would become two
```

</details>

### `ReadLines`

Wraps [`read_lines`](logic/README_FILE_READ.md#read_lines) — the file as a list of lines.

**Constructor options:**

* `encoding` (*EncodingName*, default `"utf-8-sig"`)
* `errors` (*EncodingErrors*, default `"strict"`)
* `keep_ends` (*bool*, default `False`): Every line keeps its **original** line ending.

**Main input:** a path (`PathLike`). **Returns:** `list[str]`.

**Example usage:**

```python
ReadLines()("a.txt")                        # -> ['one', 'two', 'three']
ReadLines(keep_ends=True)("crlf.txt")       # -> ['one\r\n', 'two\r\n', 'three']

def drop_blank(lines):
    return [line for line in lines if line.strip()]

clean = ReadLines() >> drop_blank >> WriteLines(path="clean.txt")
```

**Notes.** Only `"\n"`, `"\r\n"` and `"\r"` end a line; a form feed or a Unicode separator
(`\x0c`, `\u2028`, ...) stays inside its line — unlike `str.splitlines`. An empty file gives
`[]`; a last line without a terminator is returned as it is. The whole file is loaded; for
huge files use the `iter_lines` function directly (a generator has no action).

<details>
<summary>🔍 Under the hood</summary>

```python
ReadLines = create_action(read_lines, main_param="path", class_name="ReadLines")

# the function it wraps, in short:
source = normalize_path(path)
text = decode_bytes(read_bytes(source), source, encoding=encoding, errors=errors)
lines = io.StringIO(text, newline="").readlines()       # splits only on real line endings
return lines if keep_ends else [strip_line_ending(line) for line in lines]
```

</details>

### `ReadBytes`

Wraps [`read_bytes`](logic/README_FILE_READ.md#read_bytes) — the raw content of a file.
The core every other reader is built on.

**Constructor options:** none.

**Main input:** a path (`PathLike`). **Returns:** `bytes`.

**Example usage:**

```python
ReadBytes()("logo.png")                         # -> b'\x89PNG\r\n...'

checksum_input = ReadBytes() >> len             # a plain function is a valid step too
```

**Notes.** Nothing is decoded or translated — line endings arrive exactly as stored. A
locked file or a permission problem is an `AccessError` card, not a bare `PermissionError`.

<details>
<summary>🔍 Under the hood</summary>

```python
ReadBytes = create_action(read_bytes, main_param="path", class_name="ReadBytes")

# the function it wraps, in short:
source = resolve_source_file(path, "read")        # normalized, and a regular file
try:
    return source.read_bytes()
except OSError as caught_exc:
    raise_file_access_error(source, "read", caught_exc)
```

</details>

### `ReadJson`

Wraps [`read_json`](logic/README_FILE_READ.md#read_json) — reads a file and parses it as JSON.

**Constructor options:**

* `encoding` (*EncodingName*, default `"utf-8-sig"`): So a BOM written by a Windows tool
  does not break parsing.
* `errors` (*EncodingErrors*, default `"strict"`)

**Main input:** a path (`PathLike`). **Returns:** the parsed value (`Any`) — a dict, list,
str, int, float, bool or `None`.

**Example usage:**

```python
ReadJson()("config.json")                      # -> {'debug': True, 'retries': 3}

settings = ReadJson() >> (lambda cfg: cfg["retries"])
```

**Notes.** A syntax error is a `ConversionError` card **with line and column**; so are
undecodable bytes and an empty file. `NaN` is accepted, as in the standard library. The
whole document is held in memory.

<details>
<summary>🔍 Under the hood</summary>

```python
ReadJson = create_action(read_json, main_param="path", class_name="ReadJson")

# the function it wraps, in short:
source = normalize_path(path)
text = read_text(source, encoding=encoding, errors=errors)       # BOM tolerant
try:
    return json.loads(text)
except json.JSONDecodeError as caught_exc:
    raise_json_decode_error(source, caught_exc)                  # a card with line and column
```

</details>

# Write

The **content** is the pipeline value; the **target** is the required option `path`. All
seven return the normalized target `Path`. For the options `encoding`, `errors`, `newline`,
`overwrite`, `use_draft` and `sync` see [Shared options](#shared-options). Common errors:
`StateError` (a directory occupies the target), `AlreadyExistsError` (`overwrite=False`),
`AccessError` (the OS refuses), `ConversionError` (a character cannot be encoded).

### `WriteText`

Wraps [`write_text`](logic/README_FILE_WRITE.md#write_text) — writes the text flowing in to
the configured `path`.

**Constructor options:**

* `path` (*PathLike*, **required**): The target file. Its folder is created if missing.
* `encoding` (default `"utf-8"`), `errors` (`"strict"`), `newline` (`"\n"`),
  `overwrite` (`True`), `use_draft` (`True`), `sync` (`False`).

**Main input:** `text` (*str*). **Returns:** `Path`.

**Example usage:**

```python
WriteText(path="out/report.txt")("hello")                     # -> <cwd>/out/report.txt
WriteText(path="out/win.txt", newline="\r\n")("a\nb")         # file holds b'a\r\nb'
WriteText(path="out/czech.txt", encoding="cp1250")("příliš")

loud = ReadText() >> str.upper >> WriteText(path="out/loud.txt")
loud("notes.txt")
```

**Notes.** The text is encoded in memory **first**, so the old file is never truncated by a
failing encode. `encoding="utf-8-sig"` writes the BOM at the start of the new file — which
is what that encoding means. `overwrite=False` with a draft is a fail-fast check, not a
guarantee against a race; the in-place mode (`use_draft=False`) is exact.

<details>
<summary>🔍 Under the hood</summary>

```python
WriteText = create_action(write_text, main_param="text", class_name="WriteText")

# the function it wraps, in short:
target = normalize_path(path)
data = encode_text(text, target, encoding=encoding, errors=errors, newline=newline)   # may fail — disk untouched
return write_bytes(target, data, overwrite=overwrite, use_draft=use_draft, sync=sync)
```

</details>

### `WriteLines`

Wraps [`write_lines`](logic/README_FILE_WRITE.md#write_lines) — writes the lines flowing in,
one per line. The counterpart of `ReadLines`.

**Constructor options:**

* `path` (*PathLike*, **required**)
* `encoding`, `errors`, `newline`, `overwrite`, `use_draft`, `sync` — as in
  [`WriteText`](#writetext).
* `trailing_newline` (*bool*, default `True`): The last line is terminated too, as POSIX
  tools expect.

**Main input:** `lines` (*Collection[str]*). **Returns:** `Path`.

**Example usage:**

```python
WriteLines(path="out/list.txt")(["a", "b"])                           # file: 'a\nb\n'
WriteLines(path="out/list.txt", trailing_newline=False)(["a", "b"])   # file: 'a\nb'

ReadLines() >> sorted >> WriteLines(path="sorted.txt")
```

**Notes.** Each item is written **without** its own line ending — pass lines as `ReadLines`
returns them by default. An item that already ends with `"\n"` gets an empty line after it,
and an item containing `"\n"` becomes more than one line. An **empty collection always gives
an empty file**, even with `trailing_newline=True`. It takes a `Collection`, not a generator
(the lines are used twice).

<details>
<summary>🔍 Under the hood</summary>

```python
WriteLines = create_action(write_lines, main_param="lines", class_name="WriteLines")

# the function it wraps, in short:
text = "\n".join(lines)
if trailing_newline and lines:                   # never turn an empty collection into a lone newline
    text += "\n"
return write_text(path, text, encoding=encoding, errors=errors, newline=newline,
                  overwrite=overwrite, use_draft=use_draft, sync=sync)
```

</details>

### `WriteAggregated`

Wraps [`write_aggregated`](logic/README_FILE_WRITE.md#write_aggregated) — joins the text
fragments flowing in with a separator and writes them as one file.

**Constructor options:**

* `path` (*PathLike*, **required**)
* `separator` (*str*, default `"\n"`): Placed between consecutive fragments.
* `trailing_newline` (*bool*, default `False`): Add one `"\n"` after the last fragment.
* `encoding`, `errors`, `newline`, `overwrite`, `use_draft`, `sync` — as in
  [`WriteText`](#writetext).

**Main input:** `parts` (*Collection[str]*). **Returns:** `Path`.

**Example usage:**

```python
WriteAggregated(path="out/all.txt")(["a", "b"])                       # file: 'a\nb'
WriteAggregated(path="out/all.md", separator="\n\n---\n\n")(["intro", "body"])
WriteAggregated(path="out/ids.txt", separator="")(["12", "34"])       # file: '1234'

many_to_one = (
    CollectFiles(include_filter=HasSuffix(".md"))
    >> ForEach(ReadText())
    >> WriteAggregated(path="build/combined.md", separator="\n\n")
)
```

**Notes.** The step at the end of an extraction pipeline: several extracted texts become one
document. Unlike `WriteLines`, the join is **exact** by default — `trailing_newline` is
opt-in, and the separator can be anything (`"\n---\n"`, `""`).

<details>
<summary>🔍 Under the hood</summary>

```python
WriteAggregated = create_action(write_aggregated, main_param="parts", class_name="WriteAggregated")

# the function it wraps, in short:
text = separator.join(parts)
if trailing_newline:
    text += "\n"
return write_text(path, text, encoding=encoding, errors=errors, newline=newline,
                  overwrite=overwrite, use_draft=use_draft, sync=sync)
```

</details>

### `WriteJson`

Wraps [`write_json`](logic/README_FILE_WRITE.md#write_json) — serializes the value flowing in
to JSON and writes it.

**Constructor options:**

* `path` (*PathLike*, **required**)
* `indent` (*int | str | None*, default `2`): Spaces, a string such as `"\t"`, or `None`
  for compact output.
* `ensure_ascii` (*bool*, default `False`): Non-ASCII characters are written as they are
  (`č`, not `\u010d`).
* `sort_keys` (*bool*, default `False`): Reproducible output, clean diffs.
* `allow_nan` (*bool*, default `False`): `NaN` / `Infinity` are refused — they are not valid JSON.
* `default` (*Callable | None*, default `None`): Converts objects JSON cannot serialize, like
  `json.dumps(default=...)`.
* `trailing_newline` (*bool*, default `True`)
* `encoding`, `newline`, `overwrite`, `use_draft`, `sync` — as in [`WriteText`](#writetext).
  There is **no** `errors` option.

**Main input:** `data` (*Any* — a JSON-compatible value). **Returns:** `Path`.

**Example usage:**

```python
WriteJson(path="out/index.json", sort_keys=True)({"b": 1, "a": 2})
# out/index.json:  {\n  "a": 2,\n  "b": 1\n}\n

WriteJson(path="out/compact.json", indent=None)({"a": 1})          # {"a": 1}\n
WriteJson(path="out/paths.json", default=str)({"root": Path("src")})

report = CollectFiles() >> ForEach(FileSize()) >> WriteJson(path="out/sizes.json")
```

**Notes.** The value is serialized **in memory first**: an unserializable value, a circular
reference, `NaN` with `allow_nan=False` or mixed-type keys with `sort_keys=True` is a
`ConversionError` and the existing file stays intact. `None` is a valid value (the file
holds `null`).

<details>
<summary>🔍 Under the hood</summary>

```python
WriteJson = create_action(write_json, main_param="data", class_name="WriteJson")

# the function it wraps, in short:
target = normalize_path(path)
try:
    text = json.dumps(data, indent=indent, ensure_ascii=ensure_ascii, sort_keys=sort_keys,
                      allow_nan=allow_nan, default=default)
except (TypeError, ValueError) as caught_exc:
    raise_json_encode_error(target, caught_exc)            # ConversionError — the disk is untouched
if trailing_newline:
    text += "\n"
return write_text(target, text, encoding=encoding, newline=newline,
                  overwrite=overwrite, use_draft=use_draft, sync=sync)
```

</details>

### `WriteBytes`

Wraps [`write_bytes`](logic/README_FILE_WRITE.md#write_bytes) — writes the bytes flowing in.
The first core writer: every other writer ends here.

**Constructor options:**

* `path` (*PathLike*, **required**)
* `overwrite` (*bool*, default `True`), `use_draft` (*bool*, default `True`), `sync` (*bool*,
  default `False`).

**Main input:** `data` (*bytes*). **Returns:** `Path`.

**Example usage:**

```python
WriteBytes(path="out/blob.bin")(b"\x00\xff")                  # -> <cwd>/out/blob.bin

copy_content = ReadBytes() >> WriteBytes(path="out/copy.bin", overwrite=False)
```

**Notes.** With a draft (default) the data goes into a private file next to the target and
replaces it in one atomic step; a crash leaves the old file exactly as it was. Direct mode
(`use_draft=False`) truncates the target first and is the documented price of speed.
Only `bytes` is accepted (not `bytearray`).

<details>
<summary>🔍 Under the hood</summary>

```python
WriteBytes = create_action(write_bytes, main_param="data", class_name="WriteBytes")

# the function it wraps, in short (error handling omitted):
target = prepare_write_target(path, "write", overwrite=overwrite)     # normalize, refuse a directory, make the folder
if use_draft:
    with SafeFileWriter(target, mode="wb", sync=sync) as handle:      # draft-and-swap
        handle.write(data)
    return target
with target.open("wb" if overwrite else "xb") as handle:              # "xb" closes the check-then-write gap
    handle.write(data)
return target
```

</details>

### `AppendText`

Wraps [`append_text`](logic/README_FILE_WRITE.md#append_text) — appends the text flowing in
to the configured `path`, creating the file if it does not exist.

**Constructor options:**

* `path` (*PathLike*, **required**)
* `encoding` (default `"utf-8"`), `errors` (`"strict"`), `newline` (`"\n"`),
  `use_draft` (**`False`**), `sync` (`False`). There is **no** `overwrite` option.

**Main input:** `text` (*str*). **Returns:** `Path`.

**Example usage:**

```python
log = AppendText(path="logs/run.log")
log("started\n")
log("finished\n")                           # run.log: 'started\nfinished\n'
```

**Notes.** A log-like output: every run adds what it produced. `use_draft=False` is the
default because a safe append has to copy the whole existing file into a draft first — the
cost grows with every append. The in-place append can at worst leave a partial **last**
chunk; the older content is never touched. Whoever needs all-or-nothing asks for
`use_draft=True`. A BOM codec (`utf-8-sig`, `utf-16`) writes its BOM only at the start of a
file, never in the middle. The caller owns encoding consistency: appending `cp1250` text to a
`utf-8` file produces a mixed file.

<details>
<summary>🔍 Under the hood</summary>

```python
AppendText = create_action(append_text, main_param="text", class_name="AppendText")

# the function it wraps, in short:
target = normalize_path(path)
data = encode_text(text, target, encoding=encoding, errors=errors, newline=newline)
data = drop_redundant_bom(data, target, encoding)       # a BOM belongs at the start of a file
return append_bytes(target, data, use_draft=use_draft, sync=sync)
```

</details>

### `AppendBytes`

Wraps [`append_bytes`](logic/README_FILE_WRITE.md#append_bytes) — appends the bytes flowing in,
creating the file if it does not exist. The second core writer.

**Constructor options:**

* `path` (*PathLike*, **required**)
* `use_draft` (*bool*, default `False`), `sync` (*bool*, default `False`). No `overwrite`.

**Main input:** `data` (*bytes*). **Returns:** `Path`.

**Example usage:**

```python

chunks(b"\x01\x02")
chunks(b"\x03")                              # stream.bin: b'\x01\x02\x03'
```

**Notes.** Collecting binary chunks into one file as they are produced. Appending an empty
`bytes` to a missing file creates an empty file.

# Operations

Work with the file **itself**. All six change the disk and return the normalized `Path` of
the result. A symlink is handled as described on each card.

### `CopyFile`

Wraps [`copy_file`](logic/README_FILE_OPERATIONS.md#copy_file) — copies the file flowing in
to the configured `destination`, keeping its permissions and times.

**Constructor options:**

* `destination` (*PathLike*, **required**): The target **file** path — never a folder to
  copy into. Its folder is created if missing.
* `overwrite` (*bool*, default `False`): An existing destination raises.
* `sync` (*bool*, default `False`): Force the copy to stable storage.

**Main input:** `source` (`PathLike`). **Returns:** the destination `Path`.

**Example usage:**

```python
CopyFile(destination="backup/a.txt")("a.txt")                  # -> <cwd>/backup/a.txt
CopyFile(destination="backup/a.txt", overwrite=True)("a.txt")
```

**Notes.** The copy is **atomic**: the destination is either the complete copy or
untouched, never a truncated file. Source and destination are normalized with symlinks
resolved — the **content** is copied to where the destination path leads. Errors:
`NotFoundError` / `StateError` (the source is missing or not a file), `ParamError` (source
and destination are the same file), `StateError` (a directory occupies the destination),
`AlreadyExistsError` (`overwrite=False`), `AccessError`.

<details>
<summary>🔍 Under the hood</summary>

```python
CopyFile = create_action(copy_file, main_param="source", class_name="CopyFile")

# the function it wraps, in short:
source_path = resolve_source_file(source, "copy")                  # verified, a regular file
destination_path = normalize_path(destination)
prepare_destination(source_path, destination_path, "copy", overwrite=overwrite)   # same file? a directory? already there?
ensure_parent_dir(destination_path)
copy_atomically(source_path, destination_path, sync=sync)          # through a draft
return destination_path
```

</details>

### `MoveFile`

Wraps [`move_file`](logic/README_FILE_OPERATIONS.md#move_file) — moves or renames the file
flowing in to the configured `destination`, across folders **and across devices**.

**Constructor options:**

* `destination` (*PathLike*, **required**): The new **file** path. Its folder is created if
  missing.
* `overwrite` (*bool*, default `False`)

There is **no** `sync` option: a same-device rename has no data to flush, and the option
would promise more than the OS can keep.

**Main input:** `source` (`PathLike`). **Returns:** the destination `Path`.

**Example usage:**

```python
MoveFile(destination="archive/2026/report.txt")("report.txt")
MoveFile(destination="A.txt", overwrite=True)("a.txt")          # a case-only rename
```

**Notes.** Works on the directory **entry**: a symlink is moved as a link, not as the file it
points to. Between devices (`G:` → `C:`) it falls back to an atomic copy followed by removing
the source; if the copy fails, the source is kept. A case-only rename (`a.txt` → `A.txt`) is
allowed on Windows. Errors: `NotFoundError`, `StateError` (the source is a directory, or a
directory occupies the destination), `ParamError` (same file), `AlreadyExistsError`,
`AccessError`.

<details>
<summary>🔍 Under the hood</summary>

```python
MoveFile = create_action(move_file, main_param="source", class_name="MoveFile")

# the function it wraps, in short (error handling omitted):
source_path = normalize_entry_path(source)               # a symlink in the final position stays a symlink
destination_path = normalize_entry_path(destination)
prepare_destination(source_path, destination_path, "move", overwrite=overwrite)
ensure_parent_dir(destination_path)
try:
    replace_with_retry(source_path, destination_path)    # one atomic rename (Windows locks are retried)
except OSError as caught_exc:
    if not is_cross_device_error(caught_exc):
        raise_file_transfer_error(source_path, destination_path, "move", caught_exc)
    move_across_devices(source_path, destination_path)   # copy completely, then remove the source
return destination_path
```

### `DeleteFile`

Wraps [`delete_file`](logic/README_FILE_OPERATIONS.md#delete_file) — deletes the file or
symlink flowing in (the **link itself**, never its target).

**Constructor options:**

* `missing_ok` (*bool*, default `False`): A missing path is accepted silently.
* `force` (*bool*, default `False`): A read-only file is made writable first (a problem on
  Windows, where read-only files cannot be deleted). Off by default — removing a protection
  is an explicit choice.

**Main input:** `path` (`PathLike`). **Returns:** the normalized path of the (now deleted) entry.

**Example usage:**

```python
DeleteFile()("cache/old.bin")                                  # -> <cwd>/cache/old.bin
DeleteFile(missing_ok=True)("cache/maybe.bin")                 # no error if it is already gone

cleanup = CollectFiles(include_filter=HasSuffix(".tmp")) >> ForEach(DeleteFile(force=True))
safe = NormalizeEntryPath() >> DeleteFile()                    # the entry itself, never a link's target
```

**Notes.** A dangling symlink can be deleted too. A **directory** raises `StateError` and is
never touched. `NotFoundError` if nothing exists there and `missing_ok=False`; `AccessError`
if the OS refuses. The flag of a symlink's *target* is never touched by `force`. A file
removed by someone else between the check and the delete is the outcome `missing_ok=True`
asks for, and an honest "not found" otherwise.

<details>
<summary>🔍 Under the hood</summary>

```python
DeleteFile = create_action(delete_file, main_param="path", class_name="DeleteFile")

# the function it wraps, in short (error handling omitted):
entry = normalize_entry_path(path)                       # "link" means the link itself
exists = os.path.lexists(entry)                          # a dangling symlink exists as an entry
is_file_entry = exists and (entry.is_symlink() or entry.is_file())
if not exists:
    if missing_ok:
        return entry
    raise_file_not_found_error(entry, "delete")
if not is_file_entry:
    raise_not_a_file_error(entry, "delete")              # a directory is not deleted here
entry.unlink()
return entry
```

</details>

### `BackupFile`

Wraps [`backup_file`](logic/README_FILE_OPERATIONS.md#backup_file) — creates an atomic backup
copy **next to** the file flowing in, never overwriting an older backup.

**Constructor options:**

* `suffix` (*str*, default `".bak"`): Appended to the backup's name. `""` is allowed.
* `timestamp` (*bool*, default `True`): Insert a `YYYYMMDD_HHMMSS` stamp before the extension.
* `sync` (*bool*, default `False`)

**Main input:** `path` (`PathLike`). **Returns:** the **backup's** `Path` — not the original.

**Example usage:**

```python
BackupFile()("report.txt")                      # -> <cwd>/report_20261013_142530.txt.bak
BackupFile(timestamp=False)("report.txt")       # -> <cwd>/report.txt.bak
BackupFile(timestamp=False)("report.txt")       # again -> <cwd>/report.txt (1).bak  (nothing overwritten)
BackupFile(suffix=".orig")("report.txt")        # -> <cwd>/report_20261013_142530.txt.orig
```

**Notes.** The name has the shape `<stem>[_<timestamp>]<extension><suffix>`. The copy is
atomic: a backup is either complete or does not exist (an interrupted copy can never leave
a truncated `.bak` that looks real). Two backups within one second get `(1)`, `(2)`, ...
instead of replacing each other. A malformed `suffix` (`"bak"`, `"/x"`) is a `ParamError`
raised when the action **runs**, as is `suffix=""` together with `timestamp=False` (the
"backup" would be the source itself). `OperationError` if no free numbered name can be found.

<details>
<summary>🔍 Under the hood</summary>

```python
BackupFile = create_action(backup_file, main_param="path", class_name="BackupFile")

# the function it wraps, in short (error handling omitted):
source = resolve_source_file(path, "backup")
name_parts = [source.stem]
if timestamp:
    name_parts.append(build_timestamp())
candidate = source.with_name("_".join(name_parts) + source.suffix + suffix)    # <stem>[_<stamp>]<ext><suffix>
backup_path = make_unique_path(candidate)                # two backups in one second never collide
copy_atomically(source, backup_path, sync=sync)          # complete, or does not exist
return backup_path
```

</details>

### `FileSize`

### `FileHash`

Wraps [`file_hash`](logic/README_FILE_INSPECT.md#file_hash) — hashes the content of the file
flowing in, reading it in chunks.

**Constructor options:**

* `algorithm` (*HashAlgorithm*, default `"sha256"`): `"md5"`, `"sha1"`, `"sha224"`, `"sha256"`,
  `"sha384"`, `"sha512"`, `"sha3_224"`, `"sha3_256"`, `"sha3_384"`, `"sha3_512"`,
  `"blake2b"`, `"blake2s"`. `md5` and `sha1` are for change detection and checksums only,
  never for security.
* `chunk_size` (*ByteCount*, default `1_048_576`): Bytes read at a time — a positive `int`
  (zero, negatives and `bool` are rejected).

**Main input:** `path` (`PathLike`). **Returns:** the digest as a lowercase hexadecimal `str`.

**Example usage:**

```python
FileHash()("archive.zip")                       # -> 'b5bb9d8014a0f9b1...'  (64 hex characters)
FileHash(algorithm="md5")("a.txt")              # -> '5d41402abc4b2a76b9719d911017c592'

(FileHash() & FileSize())("a.txt")              # -> ('2cf24dba...', 5)   both on the same input
```

**Notes.** Change detection and de-duplication: hash a file, compare with the stored value,
skip unchanged work. The file is never loaded whole — 1 MiB chunks keep memory flat for a
file of any size. **Content only**: two identical files in different folders hash equal. The
`shake_*` algorithms are not offered (a variable-length digest needs a length).

<details>
<summary>🔍 Under the hood</summary>

```python
FileHash = create_action(file_hash, main_param="path", class_name="FileHash")

# the function it wraps, in short:
source = resolve_source_file(path, "hash")
legacy = algorithm in ("md5", "sha1")
digest = hashlib.new(algorithm, usedforsecurity=not legacy)      # also works on FIPS-restricted systems
with source.open("rb") as handle:
    while chunk := handle.read(chunk_size):
        digest.update(chunk)
return digest.hexdigest()
```

</details>
